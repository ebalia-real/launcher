- Bedrock：Bedrock の管理ツールに必要な Microsoft Visual C++ ランタイムをランチャーがインストールします（以前は「You need VC++ Runtime 14.14…」で止まっていました）。管理ツールをインストールしたあとは「プレイ」ボタンで起動します。
- インスタンスのアイコンに、ランチャーがダウンロードしたゲームから読み込んだ Minecraft 自身のテクスチャ（ダイヤモンドのツルハシ、TNT、作業台、クリーパーなど）を使います。
- アカウントメニューから自分のプロフィール画像を選べます（いつでも Microsoft の画像に戻せます）。
- ホームのニュースの上に、カバー付きの EBALIA Mods を表示します。
- Patreon のページを見やすくしました。メンバーシップのカード、読みやすい日付と「もっと見る」付きの整った投稿を、コミュニティとニュースに表示します。
- Patreon サービスのアドレス設定を削除しました。ページの下に空の帯が出なくなり、「サポートとコミュニティ」の「と」が正しく表示されます。

# 1.1.1 (2026-10-07)

- 仮想マシンやグラフィックドライバーのないコンピューター：OpenGL がなくて Minecraft が閉じたとき、ランチャーがソフトウェア描画（プロセッサーが OpenGL を描画。Windows は Mesa、Linux はシステムの Mesa）での起動を提案します。インスタンスの設定から有効にすることもできます。Windows では Minecraft 1.13 以降で使われます。
- ゲームのダウンロードが速くなりました。Mojang のサーバーへの接続を再利用し、ライブラリを並列でダウンロードします。新規の Minecraft 1.21.1（3,900 ファイル、850 MB）は、私たちのテストで 143 秒から 28 秒になりました。
- インスタンスの背景：ランチャーの画像やコンピューター上の画像を、インスタンスのページかその設定から選べます。
- インスタンスのアイコンは、インスタンスの設定からも変更できます。
- Minecraft がエラーで閉じると、何が失敗したかの概要と、それを直すボタンが表示されます。不足している Mod（インスタンスのバージョンとローダーに合わせて Modrinth からインストール）、グラフィックドライバーのクラッシュ（AMD、NVIDIA、Intel のドライバーへのリンク、またはソフトウェア描画）、OpenGL がない、Java が違う、メモリが少なすぎる、などです。完全なログもワンクリックで見られます。
- .minecraft フォルダーの取り込み：公式 Minecraft Launcher のフォルダーと、その形式を使うランチャー（TLauncher、SKLauncher など）のバージョンフォルダーを、圧縮されていてもいなくても取り込めます。Minecraft のバージョンとローダーはバージョンのプロフィールから、ない場合は Mod 自体から判断します。これらのフォルダーはコンピューター上で見つかったインスタンスの一覧にも表示され、すぐに取り込めます。アカウントのファイルは決してコピーしません。
- インスタンスのフォルダー名が、ランダムな番号ではなくインスタンス名になりました。インスタンス名を変えるとフォルダー名も変わります。以前のバージョンのインスタンスは起動時に名前が変わり、そのまま動作します（使用中のフォルダーは古い名前のままです）。
- 他のランチャーのインスタンスを、インスタンスのフォルダーに直接貼り付けられます（Prism Launcher、MultiMC、CurseForge アプリ、FTB App、ATLauncher、GDLauncher、Modrinth App、TLauncher、.minecraft のバージョンフォルダー、.zip と .mrpack ファイル）。ランチャーは起動中でも、Minecraft のバージョンとローダー付きのインスタンスに変換します。元のものは、変換がうまくいったときだけインスタンスのごみ箱に移ります。
- どの取り込みでも、Mod がパックの Minecraft バージョンとローダーに合っているかを確認し、合わないものを名前で示します。

# 1.1.0 (2026-10-05)

- EBALIA の公開アプリケーション ID（`microsoft-client-id.txt`）で Microsoft サインインが有効になりました。
- Microsoft アカウントにプロフィール画像（アカウントの Xbox ゲーマーアイコン。ない場合は Minecraft スキンの顔）を、サイドバー、ホームのプレイヤーカード、アカウントメニュー、設定に表示するようになりました。画像は `mc/avatars` に保存されます。
- EBALIA のマスコット Silence が、インタラクティブツアーとガイドとチュートリアルのページに、アニメーション付きで登場します。浮かぶ、呼吸する、まばたきする、目が光る、ナイフが揺れる、ステップごとに跳ねる、強調表示された操作の方へ体を傾ける、といった動きをします。
- ポータブルモード：ランチャーの隣（AppImage または `.app` バンドルの隣）に `portable.txt` を置くと、インスタンス、アカウント、設定をその隣の `ebalia-data` フォルダーに保存します。
- Silence に 7 つのポーズ（待機、うれしい、驚き、ウインク、指差し、応援、考え中）のピクセルアートのスプライトシートができ、それぞれに話す・まばたきするコマがあります。ツアーの各ステップで専用のポーズを使います。
- 手描きの 16×16 の新しいインスタンスアイコン。コンピューター上のどんな画像も、インスタンスの作成時やあとからそのページで、インスタンスのアイコンにできます。
- インスタンスのページに、スクリーンショット（クリックで開く）とマルチプレイのサーバー一覧を表示します。サーバーの追加、コピー、削除ができ、`servers.dat` の未知の項目は保持されます。
- 翻訳の見直し：インタラクティブツアー、Patreon と作品のページ、失われたバージョンのアンインストール、Microsoft サインインのメッセージ、ランチャーの更新機能を 10 言語すべてに翻訳しました。
- ウェブサイト：インストーラー版とポータブル版のダウンロードを並べ、各パッケージの SHA-256 をコピーボタンと検証用コマンド付きで表示し、すべてのリンクが見えるようにスマートフォン向けのレイアウトを作り直しました。
- 新しいパッケージ：glibc 2.35 以降のあらゆるディストリビューション向けの Linux AppImage（Qt、libarchive、OpenSSL を同梱。CI で Debian、Fedora、Arch、openSUSE でテスト済み）でアプリ内更新に対応、Windows のポータブル `.zip`、Linux のポータブル `.tar.gz`、Apple Silicon に加えて Intel 版の macOS ビルドを用意し、それぞれにポータブルの `.zip` があります。
- Forge と NeoForge のインスタンスを修正：ローダーのライブラリをアーティファクトと分類子ごとに統合するので、Forge のユニバーサル jar が残ります（「Failed to find system mod: forge」）。Forge 26.3、1.20.1、1.16.5、1.12.2、1.8.9、1.7.10、NeoForge 26.3 と 1.21.1、Fabric と Quilt 26.3 でゲーム内で確認しました。
- 以前のランチャーでインストールした Forge、NeoForge、Fabric、Quilt のインスタンスは、次に「プレイ」を押したときに準備し直します（ダウンロード済みのファイルは再利用します）。
- NeoForge 26.x と 1.20.1 用の NeoForge を利用できます。Fabric と Quilt は最新の安定版ローダーを選び、Forge 1.7.10〜1.12.2 は旧式のインストーラーでインストールします。
- 失われたバージョンが、Windows、macOS、Linux で Java から直接起動します（Wine 不要）。a1.1.1、Alpha 1.0.16、1.1 Patch 1、Ghost、554e、NSSS をはじめ、アーカイブされたすべてのバージョンがメニューまで到達します。アーカイブは SHA-256 で確認され、各バージョンはセーブデータを自分のフォルダーに保存します。
- `.mrpack`、CurseForge の `.zip`、Prism Launcher / MultiMC / PolyMC、CurseForge アプリ、FTB App、ATLauncher、GDLauncher、Modrinth App、Technic からのモッドパックの取り込みに、Forge、NeoForge、Fabric、Quilt、バニラで対応しました。フォルダーで包まれた ZIP や macOS・Windows で作った ZIP、あらゆる言語のファイル名、Modrinth のミラー URL と任意ファイル、CurseForge のリソースパックとシェーダーも扱えます。
- 新しいリリースがあると、サイドバーに「… に更新」ボタンが表示されます。ウェブサイトを開かずに、更新をダウンロード、検証、インストールします。
- バックグラウンドでインストールする実験的な外部 Bedrock 管理ツールを追加しました。Windows は BedrockLauncher、Linux と macOS は Android 版のエンジンを使い、Google Play での購入が必要です。Windows での購入は Android には引き継がれません。実際のプレイはすべてのプラットフォームではまだ確認できていません。
- 失われたバージョンのアンインストールを、確認とごみ箱への移動付きで追加しました。
- 処理の進行状況を下部のステータスバーに移しました。
- Windows 用の Visual C++ ランタイムを同梱し、ユーザー単位のインストーラーにデスクトップのショートカットを追加しました。
- ランチャー内に「更新して再起動」を追加しました。リリースのパッケージは SHA-256 で検証され、準備と起動テストを経てから、インストール済みのプログラムファイルと置き換えます。以前のランチャーのファイルと一時ダウンロードは、正常に起動したあとで削除します。NixOS では Nix でリリースをビルドし、共有されたストアのパスは引き続き Nix のガベージコレクションの対象です。
- 更新機能が、インスタンス、失われたバージョン、ワールド、Mod、ダウンロードしたコンテンツを削除することはありません。ゲームやインストールの実行中は更新できません。置き換えに失敗した場合は、以前のプログラムファイルを復元します。
- Windows のインストーラーは、以前のインストーラーのレジストリ形式も含めて既存のインストール先を検出し、その場で更新します。
- 初回起動時の 14 ステップのインタラクティブツアーを追加しました。操作が強調表示され、「戻る」「次へ」「スキップ」があり、ガイドとチュートリアルからもう一度見られます。
- 1.0.0 を使っている方は、組み込みの更新機能を得るために 1.1.0 を一度インストールする必要があります。それ以降の互換性のあるリリースは、ランチャーから更新されます。
- アプリケーションデータの既存の保存場所を維持しました。

ランチャーには Minecraft、アカウント、ゲームのライセンスは含まれません。Windows と macOS のパッケージには署名がありません。Linux のバイナリは Ubuntu 24.04 x64 向けです。ほかのディストリビューションでは、flake を使う NixOS も含めソースからビルドできます。
