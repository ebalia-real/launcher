- 이전 런처로 설치한 Forge, NeoForge, Fabric, Quilt 인스턴스는 다음에 플레이를 누를 때 다시 준비됩니다(받아 둔 파일은 재사용).
- NeoForge 26.x와 1.20.1용 NeoForge를 쓸 수 있습니다. Fabric과 Quilt는 가장 최신의 안정 로더를 고르고, Forge 1.7.10–1.12.2는 예전 설치 프로그램으로 설치합니다.
- 잃어버린 버전이 Windows, macOS, Linux에서 Java로 바로 실행됩니다(Wine 없이). a1.1.1, Alpha 1.0.16, 1.1 Patch 1, Ghost, 554e, NSSS를 비롯한 모든 보관 버전이 메뉴까지 열립니다. 보관 파일은 SHA-256으로 확인하고, 버전마다 저장 데이터를 자기 폴더 안에 둡니다.
- `.mrpack`, CurseForge `.zip`, Prism Launcher / MultiMC / PolyMC, CurseForge 앱, FTB App, ATLauncher, GDLauncher, Modrinth App, Technic에서 모드팩을 가져오며, Forge, NeoForge, Fabric, Quilt 또는 바닐라를 지원합니다. 폴더에 싸인 ZIP이나 macOS·Windows에서 만든 ZIP, 모든 언어의 파일 이름, Modrinth 미러 URL과 선택 파일, CurseForge 리소스 팩과 셰이더도 처리합니다.
- 새 릴리스가 나오면 사이드바에 “…(으)로 업데이트” 버튼이 나타나며, 웹사이트에 가지 않고 업데이트를 다운로드, 검증, 설치합니다.
- 백그라운드로 설치되는 실험적 외부 Bedrock 관리 도구를 추가했습니다. Windows는 BedrockLauncher를, Linux와 macOS는 Android 엔진을 쓰며 Google Play 구매가 필요합니다. Windows 구매는 Android로 이어지지 않습니다. 실제 플레이는 아직 모든 플랫폼에서 확인되지 않았습니다.
- 확인 후 휴지통으로 옮기는 잃어버린 버전 제거 기능을 추가했습니다.
- 작업 진행 상황을 아래쪽 상태 표시줄로 옮겼습니다.
- Windows용 Visual C++ 런타임을 포함하고, 사용자별 설치 프로그램에 바탕 화면 바로 가기를 추가했습니다.
- 런처 안에 업데이트 후 다시 시작을 추가했습니다. 릴리스 패키지는 SHA-256으로 검증하고, 준비와 실행 테스트를 거친 뒤에 설치된 프로그램 파일을 바꿉니다. 이전 런처 파일과 임시 다운로드는 정상적으로 시작한 뒤 지웁니다. NixOS는 Nix로 릴리스를 빌드하며, 공유 스토어 경로는 계속 Nix 가비지 컬렉션의 대상입니다.
- 업데이트 기능은 인스턴스, 잃어버린 버전, 월드, 모드, 다운로드한 콘텐츠를 절대 지우지 않습니다. 게임이나 설치가 진행 중이면 업데이트할 수 없습니다. 교체에 실패하면 이전 프로그램 파일을 복원합니다.
- Windows 설치 프로그램은 이전 설치 프로그램의 레지스트리 형식까지 포함해 기존 설치 폴더를 찾아 그 자리에서 업데이트합니다.
- 처음 실행할 때 나오는 14단계 대화형 둘러보기를 추가했습니다. 강조된 컨트롤, 이전/다음/건너뛰기가 있고, 가이드 및 튜토리얼에서 다시 볼 수 있습니다.
- 1.0.0 사용자는 내장 업데이트 기능을 받으려면 1.1.0을 한 번 설치해야 합니다. 이후 호환되는 릴리스는 런처 안에서 업데이트됩니다.
- 기존 애플리케이션 데이터 위치를 그대로 유지했습니다.

런처에는 Minecraft, 계정, 게임 라이선스가 포함되지 않습니다. Windows와 macOS 패키지는 서명되지 않았습니다. Linux 바이너리는 Ubuntu 24.04 x64를 대상으로 하며, 다른 배포판은 flake를 쓰는 NixOS를 포함해 소스에서 빌드할 수 있습니다.
