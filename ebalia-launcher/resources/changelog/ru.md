# 1.1.1 (2026-10-07)

- Виртуальные машины и компьютеры без графического драйвера: когда Minecraft закрывается из-за отсутствия OpenGL, лаунчер предлагает запустить его с программной графикой (OpenGL рисует процессор; Mesa в Windows, системная Mesa в Linux). Её можно включить и в настройках сборки. Windows использует её для Minecraft 1.13 и новее.
- Быстрее загрузка игры: соединения с серверами Mojang переиспользуются, а библиотеки скачиваются параллельно. Свежая Minecraft 1.21.1 (3900 файлов, 850 МБ) в нашем тесте скачивалась уже не 143, а 28 секунд.
- Фоны сборок: выберите любую картинку лаунчера или свою с компьютера — на странице сборки или в её настройках.
- Значок сборки тоже можно сменить в настройках сборки.
- Когда Minecraft закрывается с ошибкой, сводка говорит, что пошло не так, и даёт кнопку, чтобы это исправить: не хватает мода (устанавливается с Modrinth для версии и загрузчика сборки), сбой графического драйвера (ссылка на драйвер AMD, NVIDIA или Intel или программная графика), нет OpenGL, не та Java или слишком мало памяти. Полный журнал — в один щелчок.
- Импорт папок .minecraft: из официального Minecraft Launcher и папок версий лаунчеров, использующих его формат (TLauncher, SKLauncher…), в архиве или без. Версия Minecraft и загрузчик берутся из профиля версии или, если его нет, из самих модов. Эти папки также появляются в списке сборок, найденных на компьютере, и готовы к импорту. Файлы учётных записей никогда не копируются.
- Папки сборок называются по имени сборки, а не случайным числом; переименование сборки переименовывает её папку. Сборки из прежних версий переименовываются при запуске и продолжают работать (папка, которая используется, сохраняет старое имя).
- Вставляйте сборки других лаунчеров прямо в папку сборок (Prism Launcher, MultiMC, приложение CurseForge, FTB App, ATLauncher, GDLauncher, Modrinth App, TLauncher или папки версий .minecraft, файлы .zip и .mrpack): лаунчер превращает их в сборки с их версией Minecraft и загрузчиком, даже пока он открыт. Оригинал отправляется в корзину сборок, только если всё получилось.
- Каждый импорт проверяет, подходят ли его моды к версии Minecraft и загрузчику сборки, и называет те, что не подходят.

# 1.1.0 (2026-10-05)

- Вход через Microsoft включён с публичным идентификатором приложения EBALIA (`microsoft-client-id.txt`).
- Учётные записи Microsoft теперь показывают картинку профиля (картинку игрока Xbox; лицо скина Minecraft, если её нет) в боковой панели, в карточке игрока на главной, в меню учётной записи и в настройках. Картинки хранятся в `mc/avatars`.
- Silence, талисман EBALIA, сопровождает интерактивный тур и страницу руководства — анимированно: парит, дышит, моргает, у неё светятся глаза, покачивается нож, на каждом шаге она подпрыгивает и наклоняется к выделенному элементу.
- Портативный режим: `portable.txt` рядом с лаунчером (рядом с AppImage или пакетом `.app`) хранит сборки, учётные записи и настройки в папке `ebalia-data` рядом с ним.
- У Silence теперь есть пиксельный спрайт-лист с семью позами (покой, радость, удивление, подмигивание, указывает, ликует, размышляет), у каждой есть кадры для разговора и моргания; каждый шаг тура использует свою позу.
- Новые нарисованные вручную значки сборок 16×16. Любую картинку с вашего компьютера можно сделать значком сборки — при создании сборки или позже на её странице.
- Страница сборки показывает её скриншоты (щёлкните, чтобы открыть) и список серверов для сетевой игры, куда можно добавлять, копировать и откуда можно удалять серверы; неизвестные поля `servers.dat` сохраняются.
- Проход по переводам: интерактивный тур, страницы Patreon и творений, удаление потерянных версий, сообщения входа через Microsoft и обновлятор лаунчера переведены на все десять языков.
- Сайт: загрузки установщика и портативной версии рядом, SHA-256 каждого пакета с кнопкой копирования и командой для проверки, а также переработанная вёрстка для телефона, где все ссылки остаются видны.
- Новые пакеты: AppImage для Linux для любого дистрибутива с glibc 2.35+ (Qt, libarchive и OpenSSL внутри; проверен в CI на Debian, Fedora, Arch и openSUSE) с обновлениями из приложения, портативный `.zip` для Windows, портативный `.tar.gz` для Linux и сборки для macOS на Intel вместе с Apple Silicon, у каждой есть портативный `.zip`.
- Исправлены сборки Forge и NeoForge: библиотеки загрузчика объединяются по артефакту и классификатору, поэтому Forge сохраняет свой универсальный jar («Failed to find system mod: forge»). Проверено в игре с Forge 26.3, 1.20.1, 1.16.5, 1.12.2, 1.8.9 и 1.7.10, NeoForge 26.3 и 1.21.1, Fabric и Quilt 26.3.
- Сборки Forge, NeoForge, Fabric и Quilt, установленные прежним лаунчером, заново подготавливаются при следующем нажатии «Играть» (скачанные файлы переиспользуются).
- Доступны NeoForge 26.x и NeoForge для 1.20.1; Fabric и Quilt выбирают новейший стабильный загрузчик; Forge 1.7.10–1.12.2 ставится через свой старый установщик.
- Потерянные версии запускаются с Java напрямую в Windows, macOS и Linux (без Wine): a1.1.1, Alpha 1.0.16, 1.1 Patch 1, Ghost, 554e, NSSS и все остальные архивные версии доходят до своих меню. Архивы проверяются по SHA-256, и каждая версия хранит свои сохранения в собственной папке.
- Импорт модпаков из `.mrpack`, `.zip` CurseForge, Prism Launcher / MultiMC / PolyMC, приложения CurseForge, FTB App, ATLauncher, GDLauncher, Modrinth App и Technic с Forge, NeoForge, Fabric, Quilt или без модов. Обрабатываются ZIP, завёрнутые в папки или созданные в macOS и Windows, имена файлов на любом языке, зеркальные URL и необязательные файлы Modrinth, а также наборы ресурсов и шейдеры CurseForge.
- Когда выходит новая версия, в боковой панели появляется кнопка «Обновить до …»; она скачивает, проверяет и устанавливает обновление без посещения сайта.
- Добавлен экспериментальный внешний менеджер Bedrock с установкой в фоне. Windows использует BedrockLauncher; Linux и macOS используют движок Android и требуют покупки в Google Play. Покупка для Windows не переносится на Android. Настоящая игра пока не проверена на всех платформах.
- Добавлено удаление потерянных версий с подтверждением и перемещением в корзину.
- Ход операций перенесён в нижнюю строку состояния.
- Добавлена среда выполнения Visual C++ для Windows, а установщик для пользователя создаёт ярлык на рабочем столе.
- Добавлено «Обновить и перезапустить» прямо в лаунчере. Пакеты каждой версии проверяются по SHA-256, подготавливаются и проверяются запуском, прежде чем заменить установленные файлы программы. Прежние файлы лаунчера и временные загрузки удаляются после успешного запуска. NixOS собирает версию через Nix; общие пути хранилища по-прежнему подлежат сборке мусора Nix.
- Обновлятор никогда не удаляет сборки, потерянные версии, миры, моды или скачанное содержимое. Обновления блокируются, пока идут игры или установки. Если замена не удалась, прежние файлы программы восстанавливаются.
- Установщик Windows находит папку существующей установки, включая формат реестра прежнего установщика, и обновляет её на месте.
- Добавлен интерактивный тур из 14 шагов при первом запуске с выделением элементов, кнопками «Назад», «Далее» и «Пропустить» и повтором из руководства.
- Пользователям 1.0.0 нужно один раз установить 1.1.0, чтобы получить встроенный обновлятор; следующие совместимые версии обновляются из лаунчера.
- Прежнее расположение данных приложения сохранено.

Лаунчер не включает Minecraft, учётные записи и лицензии игры. Пакеты для Windows и macOS не подписаны. Двоичный файл для Linux рассчитан на Ubuntu 24.04 x64; на других дистрибутивах можно собрать из исходного кода, включая NixOS через flake.
