# Sidebar icons

16×16 pixel art in a block-game style. Drawn for EBALIA: a grass block (Home), a compass, a ghost (lost versions), a
chest (packs), a player (skins), a sheet of paper (news), two players (community), a book (guide), a bedrock block, a
clock (changelog) and an anvil (settings); `scripts/navigation_icons.py` draws them, run it from `ebalia-launcher/` after
changing it. None is taken from the game.

The pickaxe (Instances) is Minetest Game's diamond pickaxe, CC BY-SA 3.0 by its contributors: see `LICENSE-minetest.txt`. The launcher enlarges them
by whole steps (32 pixels in the sidebar) so the pixels stay sharp.
