# EBALIA website

Public website: https://ebalia.gitgud.site/

The deployment source is the `site` directory of https://gitgud.io/ebalia/ebalia.gitgud.site.
GitGud Pages publishes it using `.gitlab-ci.yml`.

The language follows the browser's preferred languages unless the visitor chooses a language manually. The preference is saved locally. Supported languages: Spanish, English, Portuguese, French and German.

The logo, the launcher preview and the mod icons are embedded in index.html because separate image requests returned HTTP 403 from the hosting provider. Their original files are retained in assets for editing. Keep the embedded copies in sync when replacing artwork.

Download links are populated from the latest stable release in GitHub or GitGud, checked every minute while the page is visible. No package is advertised as downloadable before its asset exists.

The mods section lists EBALIA's projects on CurseForge (author EBALIA) and Modrinth (user EBALIA). site.js takes their downloads, names and pictures from https://raw.githubusercontent.com/ebalia-real/launcher/live/mods.json, which a GitHub workflow refreshes every hour (site-src/live.py); a mod that comes out or is new joins the page by itself. Rebuilding the page (site-src/README.md) refreshes the numbers written in it and the link preview cards.

`index.html` and `es/ en/ pt/ fr/ de/` are generated by `site-src/build.py`. Every page shows its text in the visitor's
language; the folders only set the language of the link preview card (Open Graph / Twitter tags), because Discord,
WhatsApp and Telegram fetch the page once from their own servers and show the same card to everyone. The cards are
`og/ebalia-<lang>.jpg`, served from raw.githubusercontent.com since gitgud.site refuses image files.
The launcher version and its release date are written at build time and refreshed live by downloads.js.
